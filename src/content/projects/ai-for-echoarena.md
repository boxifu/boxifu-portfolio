## Overview

AI For EchoArena was a UC Berkeley research project that recreated elementary training scenarios for the game EchoArena and presented them in a personalized sequence to individual trainees. A knowledge-tracing model estimated trainee skill mastery and adjusted training curriculum at runtime.

The research focused on personalized XR training for psychomotor skills, using probabilistic task programs and Bayesian knowledge tracing to support adaptive practice sequences.

## Contributions

- Implemented a knowledge-tracing model and curriculum generation system.
- Built elementary training scenes using the Scenic programming language.
- Implemented metrics data collection during training.
- Created non-player character movement and action animation.
- Worked on disk, environment, and player interaction behavior.
- Built EchoArena map and 3D environment support.
