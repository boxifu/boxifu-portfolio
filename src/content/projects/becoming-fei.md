## Overview

Becoming Fei is a USC ICT educational game that helps novice learners understand the fundamentals of machine learning. The game focuses on the impact of data, algorithm choice, model evaluation, and the broader reasoning process behind trained models.

The game integrates learning with gameplay and uses narrative structure to connect educational objectives with player achievements. The old portfolio notes that Becoming Fei was formerly known as Basic AI 4 All, was developed under the USC ICT Human-Centered AI Lab, and received support from the United States Army DEVCOM Soldier Center.

## Contributions

- Led programming work for dialogue systems used by characters and educational instruction.
- Implemented first-person shooting mechanics with equipment maintenance.
- Built quest systems, interactable spawning and gathering, crafting, and inventory systems.
- Implemented user login, save systems, and developer logging systems.
- Organized game flow in Figma to keep design and implementation communication clear within the team.
- Designed UI interaction flows, combat and item systems, simulated machine-learning training systems, world view, character story, and narrative structure.
- Worked on Unity WebGL deployment support.
- Created UI layout and theme unification, UI and character animations, opening cutscene material, transitions, sprite assets, and prepared other visual assets.
- Used Unity GAIA terrain tools, procedural placement, post-processing, collision setup, and particle systems.
- Helped onboard and mentor student volunteers and interns, prepared marketing and publication materials, and demonstrated the game at I/ITSEC 2025 as a Serious Game Competition finalist.
