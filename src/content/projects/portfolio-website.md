This portfolio is built as a maintainable static website rather than a single disposable page. It separates project content from layout, keeps dependencies intentionally small, and uses Astro's file-based routing so future pages can be added without changing the overall architecture.

The project also serves as a living example of the site's editing model: project metadata appears in frontmatter, while longer project notes live in Markdown.
