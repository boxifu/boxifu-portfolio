## Overview

Unnamed Surgeon Game 是 2024 Global Game Jam 在 USC Games 场地制作的项目，主题是 “Make Me Laugh”。玩家扮演一名需要在灯光耗尽前整理手术室的外科医生。

核心循环是寻找手术器械，同时保证医生和手术台周围有足够灯光。当灯光开始变暗时，玩家可以用物品制造有趣声音，让灯光重新亮起。

## Contributions

作为程序，我负责：

- 实现 cabinet 和 closet 的打开机制。
- 实现角色与可交互物体的动画系统。
- 实现教程与 UI 行为。

作为美术与美术技术，我负责：

- 通过场景布局、灯光和后处理营造恐怖喜剧氛围。
- 整理 3D 模型、贴图、材质和场景资产。
- 制作标题/菜单展示与相关视觉 polish。

## Development Notes

该项目是在 game jam 节奏下快速完成的，因此设计重点放在清晰的房间目标、简单直接的物品交互，以及即时反馈的喜剧恐怖灯光循环上。页面结构沿用其他游戏项目页的格式：视觉 hero、截图展示、开发文档预览，以及可试玩的 itch.io 嵌入。
